# Grounded Answer and Summary Generation

Use Amazon Bedrock language models to produce answers and document summaries grounded in retrieved or selected source chunks.

Build model requests from versioned prompts and source context. Return citations tied to actual supplied chunks and preserve query/answer IDs. Support an insufficient-evidence response when sources do not support an answer. Persist the retrieval context needed for feedback and evaluation.
