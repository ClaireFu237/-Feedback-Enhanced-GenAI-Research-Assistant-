# Research Assistant Interface

Provide document upload, ingestion status, search, source-grounded Q&A, summarization, and feedback controls.

Streamlit is the proposed minimal frontend for the first version; React remains an alternative from the proposal. Call backend APIs rather than AWS persistence directly. Display source citations, allow users to inspect retrieved passages, and show helpfulness and evaluation trends. A local demo frontend is sufficient initially.
